- **One list, of records** (2026-09-29): the Live tab's "On air" list (`GET /api/races`) has one row per race read off air in the last 30 minutes, at the position of its latest read, with a switch to show only those with alerts. ## Model trial 2026-09-26 (Anthropic vs OpenRouter)

**Setup.** `makeLiveLlmClient` routes slash model IDs to OpenRouter; `node --env-file-if-exists=../../.env --import tsx src/tools/verifyExtraction.ts all 2 --recall-model X` scores exact golden reproduction (every field) and totals the measured cost per model. Round 1 = all 23 frame goldens × 2 runs; round 2 = the 8 hardest goldens (called/uncalled on each surface, the badge-less FL-22 board, the mid-flip ticker) × 20 runs. $/hour is at the 5 s cadence on the golden mix, which is fullscreen/lower-third heavy (a real hour is ticker-heavier and ~20% cheaper). Total spend: ≈ $8.9 Anthropic, ≈ $3.8 OpenRouter.

**Reading.** Pass 1 stays **Haiku 4.5** — nothing cheaper read the whole frame as reliably (Gemini bleeds the party chip, Flash-Lite drops boards). For the crop read, **Gemini 3.8 Flash at low reasoning matches Sonnet 4.6 exactly on the hard eight (160/160 each) at 42% of the cost** — ≈ $6/h against ≈ $14/h, ≈ $36 instead of ≈ $85 for a six-hour night. Sonnet 5 is not the drop-in it looked like in round 1: it regressed on the two newest goldens where 4.6 did not. Everything cheaper than Gemini either invents the `% IN` badge or hallucinates a ✓, the two errors this system exists to catch. What Gemini costs in return: a second vendor on air night (OpenRouter dropped connections under 12-way concurrency — the client now retries — and its prepaid balance ran out mid-trial), and a re-freeze of the goldens.

**Budget note:** the trial exhausted the Anthropic key's configured usage cap and the OpenRouter balance in one afternoon (twelve `verify` loops in parallel); both were raised the same day and the cut-short runs re-done. Check headroom before the next multi-config run.

**Switched 2026-09-26.** `DEFAULT_RECALL_MODEL` is `gemini-3.8-flash`, which `makeLiveLlmClient` sends straight to Google's Interactions API (`googleClient.ts`: inline image, forced function tool, `thinking_level: 'low'`, `store: false`, retries); every live tool builds that client and refuses to start without the keys its models need. The 23 frame goldens were re-captured with the new crop reader and their observations diffed against the pre-switch copies: 23 of 23 identical (names case-insensitive), with the goldens now recording Haiku + `gemini-3.8-flash` calls. Session goldens replay recorded observations, not LLM calls, so they did not need re-freezing. Direct spot-check before the switch: `verify` with `--recall-model gemini-3.8-flash` reproduced 40/40 on the eight hard goldens × 5 and 23/23 on all goldens × 1, ≈ $6/h, before the constant changed. Sonnet 4.6 stays available as `recallModel: 'claude-sonnet-4-6'` (or `--recall-model` on the tools); the OpenRouter form `google/gemini-3.8-flash` runs the same model through the router for side-by-side trials.

## Useful commands

Run from `packages/checker` (`npm test` and `npx tsc --noEmit && npx eslint .` also work at the repo root, covering both packages).

```bash
npm test                                              # 286 tests, hermetic (no API key)
npx tsc --noEmit && npx eslint .
npm run backend                                          # full live system + web view (needs .env + VPN)
npm run chrome                                        # the DirecTV Chrome the air capturer attaches to (CDP :9222)
npm run frontend:dev                                       # the web view on :5173
node --import tsx src/runtime/replayMain.ts <sessionId> [--serve] [--speed=N]    # replay a session; --serve plays it behind the web view
node --env-file-if-exists=../../.env --import tsx src/tools/verifyExtraction.ts all 2 --recall-model <id>            # model comparison: exact rate per golden + measured $/hour; slash IDs go to OpenRouter
node --env-file-if-exists=../../.env --import tsx src/tools/importVideo.ts <mp4> [fps]                   # dry-run the air pipeline over a recording → a session (needs key)
node --import tsx src/tools/freezeSessionGolden.ts <sessionId> <goldenName>    # session golden → recordings/goldens/sessions/
node --import tsx src/tools/freezeSessionGolden.ts --refreeze <goldenFile>     # recompute expectations after an intentional rule change (review the diff)
node --env-file-if-exists=../../.env --import tsx src/tools/captureGolden.ts <framePng> <name>           # frame golden (live, needs key); reference frames are referenced in place
node --env-file-if-exists=../../.env --import tsx src/tools/captureGolden.ts --from-session <sessionId> <frameHash> <name>   # frame golden from a recorded session (no key)
node --env-file-if-exists=../../.env --import tsx src/tools/captureGolden.ts --refreeze <golden.json>... # recompute a frame golden's observations from its recorded responses (no key)
node --env-file-if-exists=../../.env --import tsx src/tools/probeFrame.ts <framePng>                           # one live extractFrame; prints observations, ">N" floors, MISSING fields
node --env-file-if-exists=../../.env --import tsx src/tools/measureCall.ts <framePng> <expected> [runs] [--template <id>]   # check-mark reliability
node --env-file-if-exists=../../.env --import tsx src/tools/verifyExtraction.ts <goldenName> [runs]                 # N live runs vs a golden, field-by-field
node --import tsx src/tools/calibrate.ts <templateId> <framePng>          # crop a captureRegion to eyeball it
```

API keys live in the gitignored root `.env` (`GEMINI_API_KEY=…` for the live reads); replay, goldens, and `--refreeze` need **no key**.
